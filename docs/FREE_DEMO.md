# Бесплатный просмотр проекта: GitHub Codespaces + Expo Go

**GitHub Codespaces** — облачная машина от GitHub, которая запускается из вашего репозитория прямо в браузере.
На личном аккаунте GitHub бесплатно около **60 часов работы в месяц** на машине 2 ядра / 8 ГБ (лимит смотрите в
GitHub → Settings → Billing). Карта не нужна. Ничего ставить на ноутбук не нужно.

Что получите:
* **на ноутбуке** — админку и веб-версию заказчика (страница заявки по SMS-ссылке, тестовая оплата);
* **на iPhone** — оба мобильных приложения в **Expo Go** (QR-коды печатаются в Codespaces).

Сервер работает в тестовом режиме: SMS не отправляются (коды — в админке «Тестовые SMS»), оплата без денег,
адреса и расстояния приблизительные. В Expo Go не работают фоновый GPS и push-уведомления.

Проверено здесь: запуск стенда с нуля (база, API, админка, веб-версия, демо-данные), вход в админку с 2FA и
все её разделы, вход заказчика через веб-версию, сборка обоих приложений для iPhone. **Не проверено** (недоступно
из среды разработки): сам Codespaces и туннель Expo Go — если что-то пойдёт иначе, пришлите скриншот.

---

## Шаг 1. Создать Codespace (на ноутбуке, 15–20 минут, из них 10–15 — ожидание)

1. Откройте репозиторий проекта на github.com (вы его владелец).
2. Переключите ветку: кнопка с названием ветки → **`claude/magical-bell-a63eao`**.
3. Зелёная кнопка **Code** → вкладка **Codespaces** → **Create codespace on claude/magical-bell-a63eao**.
4. Откроется редактор в браузере. Внизу идёт подготовка — **10–15 минут** (ставятся зависимости, собираются
   сервер, админка и веб-версия, затем стенд запускается сам). Ничего не нажимайте, пока не закончится.
5. Когда в терминале появится рамка **«Демо „Ковш на Час“ запущено»** — готово. Если рамки не видно, в терминале
   (меню ☰ → Terminal → New Terminal) выполните:

   ```
   bash infra/codespace/start.sh
   ```

## Шаг 2. Сделать адреса доступными с телефона

Внизу вкладка **PORTS**. У портов **3000 (API)**, **5173 (Админка)** и **8090 (Веб-версия заказчика)** в колонке
Visibility должно быть **Public**. Если там Private: правый клик по строке → **Port Visibility** → **Public**.
(Скрипт пытается сделать это сам и предупредит, если не получилось.)

## Шаг 3. Админка и веб-версия на ноутбуке

В рамке из шага 1 — адреса вида `https://<имя>-5173.app.github.dev`. Откройте адрес **Админки**:

* вход: `admin@demo.kovsh`, пароль `Demo-Kovsh-2026!`;
* 2FA: в приложении-аутентификаторе на iPhone («Пароли», Яндекс Ключ, Google Authenticator) добавьте ключ
  **вручную**: `KOVSHDEMOKOVSHDEMO2026AB`, тип — по времени; введите 6-значный код;
* раздел **Система → Тестовые SMS** — коды входа в мобильные приложения.

Адрес **Веб-версии заказчика** — то, что открывает заказчик по SMS-ссылке на заявку диспетчера.

## Шаг 4. Мобильные приложения на iPhone через Expo Go

1. На iPhone установите **Expo Go** из App Store.
2. В Codespaces откройте новый терминал (☰ → Terminal → New Terminal) и выполните:

   ```
   bash infra/codespace/expo.sh partner
   ```

   Через 1–2 минуты в терминале появится **QR-код**. Наведите на него **камеру iPhone** → нажмите на ссылку →
   откроется Expo Go с приложением «Ковш на Час Партнёр». Первая загрузка — до минуты.
3. Для приложения заказчика — ещё один терминал:

   ```
   bash infra/codespace/expo.sh client
   ```

   и так же отсканируйте его QR-код. Оба терминала держите открытыми, пока смотрите приложения.
4. Вход в приложения — по демо-номерам, код смотрите в админке → «Тестовые SMS»:

   | Приложение | Номер | Кто |
   |---|---|---|
   | Ковш на Час | +7 900 000-05-01 | заказчик (частное лицо) |
   | Ковш на Час | +7 900 000-06-01 | заказчик, руководитель организации |
   | Партнёр | +7 900 000-01-01 | руководитель компании |
   | Партнёр | +7 900 000-01-02 | диспетчер |
   | Партнёр | +7 900 000-01-03 | машинист |
   | Партнёр | +7 900 000-04-01 | независимый диспетчер |

Сценарий «заказ целиком»: в «Ковш на Час» оформите заказ (адрес — например «Варварка»), в «Партнёре» под
диспетчером примите его (таймер 40 секунд), в «Ковш на Час» оплатите (тестовая страница), назначьте машиниста,
затем войдите машинистом и нажимайте «Выехал» → «Прибыл» → «Начал» → «Завершил». Одно приложение Expo Go
держит одну сессию — для смены роли выйдите из аккаунта (вкладка «Компания» / «Профиль»).

## Шаг 5. Когда закончили

* Codespace сам останавливается через 30 минут бездействия. Чтобы не тратить часы, остановите вручную:
  github.com → ваш аватар → **Your codespaces** → «…» → **Stop codespace**.
* Повторный запуск: там же → открыть codespace — стенд запустится сам (данные сохраняются), затем снова шаг 4.
* Когда демо больше не нужно — **Delete** (данные удалятся).

## Если что-то пошло не так

| Симптом | Что сделать |
|---|---|
| нет рамки «Демо запущено» | терминал → `bash infra/codespace/start.sh`; если ошибка — пришлите последние строки |
| админка не открывается, просит войти в GitHub | порт 5173 не публичный — шаг 2 |
| Expo Go: «Something went wrong» / не подключается к серверу | порт 3000 не публичный — шаг 2; затем в Expo Go потрясите телефон → Reload |
| Expo Go: «incompatible SDK» / «Project is incompatible» | пришлите скриншот — переведу приложения на версию Expo, которую поддерживает ваш Expo Go |
| `expo.sh` долго без QR или ошибка ngrok/tunnel | Ctrl+C и запустить снова; если повторяется — пришлите текст |
| в приложении код не приходит | код не отправляется SMS — смотрите в админке «Тестовые SMS» |

## Другие бесплатные варианты (для сравнения)

* **Ноутбук с Docker Desktop и Node.js 22** (Mac/Linux, Windows — через WSL): `bash infra/codespace/setup.sh`, затем
  `bash infra/codespace/start.sh` — адреса `http://localhost:5173` и `http://localhost:8090`. Для iPhone в той же
  Wi-Fi: `EXPO_PUBLIC_API_URL=http://<IP ноутбука>:3000 bash infra/codespace/expo.sh partner`. Требует установки программ.
* **Бесплатные хостинги** (Render, Railway, Fly.io и т. п.) для этого проекта не подходят: бесплатные тарифы
  «засыпают» без запросов (останавливаются таймеры 40 секунд и подбор), не дают PostGIS и Redis вместе
  или требуют иностранную карту.
* **Стартовый грант Yandex Cloud** для новых аккаунтов позволяет запустить стенд из `docs/IPHONE_SETUP.md`
  без оплаты из своих денег, но нужна привязка карты; условия гранта уточняйте в консоли Yandex Cloud.
