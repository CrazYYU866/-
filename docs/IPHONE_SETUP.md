# Настройка тестового стенда только с iPhone

Всё делается с одного iPhone: компьютер не нужен. Команды почти не придётся набирать — сервер настроит себя сам
при первом запуске. Итог: адрес API, который вы присылаете мне, после чего я публикую оба приложения для Expo Go.

**Время:** около 40 минут ваших действий + 30–40 минут, пока сервер собирается сам.

**Пароли и ключи мне передавать не нужно.** Закрытый ключ SSH остаётся в приложении Termius на вашем iPhone;
токен GitHub вводится только в настройки вашего сервера; пароль администратора знаете только вы; токен Expo —
только через защищённую форму, которую я пришлю. Мне нужен лишь адрес API (он не секретный).

Подготовлено и проверено: скрипт самонастройки сервера прогнан от начала до конца в условиях, как на новом сервере
(отдельный пользователь, свежая копия репозитория, запуск от root) — стенд поднялся, демо-данные загрузились,
администратор создаётся от вашего пользователя. Сам Yandex Cloud и экраны его консоли на iPhone я проверить
не могу — если что-то выглядит иначе, присылайте скриншот.

## Шаг 0. Приложения из App Store

| Приложение | Зачем |
|---|---|
| **Termius** (бесплатный) | создать SSH-ключ и подключиться к серверу |
| **Expo Go** | открыть «Ковш на Час» и «Ковш на Час Партнёр» (на шаге 8) |
| Аутентификатор для 2FA админки | встроенное приложение **«Пароли»** (iOS 17+) или **Яндекс Ключ** / Google Authenticator |

Консоль Yandex Cloud и GitHub открывайте в **Safari**. Если сайт выглядит урезанным: кнопка **«аА»** в адресной строке →
**«Запросить настольный веб-сайт»**.

Текст для копирования держите в **Заметках**: вы будете собирать там две строки (ключ и токен) и один шаблон.

## Шаг 1. SSH-ключ в Termius (5 минут)

1. Откройте Termius. Если предлагает создать аккаунт — можно создать бесплатный или выбрать вариант без аккаунта, если он есть.
2. Внизу **Keychain** (связка ключей) → **+** → **Generate Key**.
3. Type: **ED25519**, Label: `kovsh-stand` → **Save**.
4. Откройте созданный ключ → **Export to clipboard** / **Copy public key** (копирование **публичной** части).
5. Вставьте в Заметки. Строка начинается с `ssh-ed25519 ` — это **публичный** ключ, его можно показывать.
   Закрытый ключ из Termius никуда не копируйте.

Если Termius не даёт создать ключ: бесплатное приложение **a-Shell** → команды `ssh-keygen -t ed25519` (Enter на все вопросы)
и `cat ~/.ssh/id_ed25519.pub` → скопировать строку. Подключаться тогда тоже через a-Shell: `ssh kovsh@<IP>`.

## Шаг 2. Токен GitHub только на чтение (5 минут)

Нужен, чтобы сервер скачал код из закрытого репозитория.

1. Safari → github.com → войдите → аватар → **Settings** → внизу **Developer settings** →
   **Personal access tokens** → **Fine-grained tokens** → **Generate new token**.
2. Token name: `kovsh-stand`; Expiration: **7 days** (после настройки сервера он больше не нужен).
3. Repository access: **Only select repositories** → репозиторий проекта (`CrazYYU866/-`).
4. Permissions → Repository permissions → **Contents: Read-only**. Остальное не трогать.
5. **Generate token** → скопируйте в Заметки (начинается с `github_pat_`). Токен показывается один раз.

## Шаг 3. Yandex Cloud: аккаунт и постоянный адрес (10 минут)

1. Safari → https://console.yandex.cloud → войдите через Яндекс ID → создайте **платёжный аккаунт** (карта).

## Шаг 4. Сервер, который настроит себя сам (10 минут)

### 4.1. Подготовьте текст настройки в Заметках

Скопируйте целиком текст ниже в новую заметку и замените **две** вещи:
* `ssh-ed25519 ВСТАВЬТЕ_ПУБЛИЧНЫЙ_КЛЮЧ_ИЗ_TERMIUS` → всю строку ключа из шага 1;
* `ТОКЕН_GITHUB` → токен из шага 2 (без пробелов, между `x-access-token:` и `@github.com`).

```yaml
#cloud-config
users:
  - name: kovsh
    groups: sudo
    shell: /bin/bash
    sudo: 'ALL=(ALL) NOPASSWD:ALL'
    ssh_authorized_keys:
      - ssh-ed25519 ВСТАВЬТЕ_ПУБЛИЧНЫЙ_КЛЮЧ_ИЗ_TERMIUS
runcmd:
  - [bash, -c, "git clone -b claude/magical-bell-a63eao https://x-access-token:ТОКЕН_GITHUB@github.com/CrazYYU866/-.git /home/kovsh/kovsh > /var/log/kovsh-stand.log 2>&1 && git -C /home/kovsh/kovsh remote set-url origin https://github.com/CrazYYU866/-.git && chown -R kovsh:kovsh /home/kovsh/kovsh && bash /home/kovsh/kovsh/infra/stand/bootstrap.sh >> /var/log/kovsh-stand.log 2>&1"]
```

Отступы (пробелы в начале строк) важны — копируйте как есть. Тот же шаблон лежит в репозитории: `infra/stand/user-data.yaml`.

### 4.2. Создайте виртуальную машину

**Compute Cloud** → **Создать виртуальную машину**:

| Поле | Значение |
|---|---|
| Образ | **Ubuntu 24.04 LTS** |
| Зона доступности | `ru-central1-a` |
| Диск | SSD, **40 ГБ** |
| Вычислительные ресурсы | **2 vCPU, гарантированная доля 100%, 4 ГБ RAM**; прерываемую ВМ не выбирать |
| Сеть | Публичный адрес → **Список** → адрес из шага 3 |
| Доступ | логин `kovsh`, SSH-ключ — строка из шага 1 |
| Метаданные (обычно в блоке «Дополнительно» / «Метаданные») | ключ **`user-data`**, значение — весь текст из 4.1 |
| Имя | `kovsh-stand` |

**Создать ВМ.** Если в сети ВМ указана группа безопасности — добавьте входящие правила TCP, источник `0.0.0.0/0`, порты **22, 80, 443**.

Если поля «Метаданные» в форме нет — не страшно: создайте ВМ без него и выполните запасной вариант из шага 5.

## Шаг 5. Дождаться готовности (30–40 минут)

В Termius: **Hosts** → **+** → **New Host**: Address — IP из шага 3, Username — `kovsh`, Key — `kovsh-stand` → сохранить → подключиться
(на вопрос о новом сервере — **Continue/Yes**). Затем:

```
tail -n 15 /var/log/kovsh-stand.log
```

Повторяйте раз в 5–10 минут. Этапы идут от `1/5` до `5/5`; готово, когда появится **СТЕНД ГОТОВ** и адреса.
Если файла ещё нет — сервер ещё запускается, подождите 2–3 минуты.

**Запасной вариант** (если метаданные не задались или в логе ошибка `git clone`): в Termius выполните по очереди —

```
git clone -b claude/magical-bell-a63eao https://github.com/CrazYYU866/-.git kovsh
```
(Username — логин GitHub, Password — токен из шага 2; символы при вставке не видны), затем
```
sudo bash kovsh/infra/stand/bootstrap.sh
```
и дождитесь **СТЕНД ГОТОВ** (те же 30–40 минут; Termius можно свернуть, но не закрывать соединение — или
запустите вместо этого `sudo nohup bash kovsh/infra/stand/bootstrap.sh > stand.log 2>&1 &` и проверяйте `tail -n 15 stand.log`).

## Шаг 7. Вход в админку и 2FA на одном iPhone (5 минут)

1. Safari → адрес **Админки** из `STAND.txt` → email и пароль из шага 6.
   Если Safari пишет «соединение не защищено» — подождите 1–2 минуты (выпускается сертификат) и обновите.
2. Включение 2FA: нажмите **«Добавить в приложение-аутентификатор»** — откроется «Пароли» или Яндекс Ключ, подтвердите добавление.
   Если ничего не открылось: скопируйте «Ключ для ручного ввода» и добавьте его в аутентификатор вручную (тип — по времени).
3. Введите 6-значный код из аутентификатора.
4. Проверьте раздел **Система → Тестовые SMS** — сюда будут приходить коды входа в приложения.

После этого удалите токен GitHub (GitHub → Settings → Developer settings → Fine-grained tokens → `kovsh-stand` → Delete):
код уже на сервере, токен больше не нужен.

## Шаг 8. Expo (5 минут) и дальше

1. Safari → https://expo.dev/signup → регистрация → подтвердить email.
2. Аватар → **Account settings** → **Access tokens** → **Create token** `kovsh-build` → сохраните в «Пароли» или Заметки. **Не присылайте в чат.**
3. Напишите мне: адрес API и «токен Expo создан». Я пришлю защищённую форму для токена, опубликую оба приложения и пришлю
   две ссылки. Откройте их на iPhone — запустится Expo Go. Вход в приложения — по демо-номерам
   (заказчик `+7 900 000-05-01`, партнёр-руководитель `+7 900 000-01-01`, диспетчер `…-01-02`, машинист `…-01-03`);
   код — в админке, раздел «Тестовые SMS».

## Если что-то пошло не так

| Симптом | Что сделать |
|---|---|
| Termius: `Connection refused / timed out` | ВМ в статусе Running? Порт 22 открыт? Подождите 2–3 минуты после создания |
| Termius: `Permission denied (publickey)` | в ВМ указан не тот ключ — проверьте строку ключа в форме ВМ и в user-data |
| в логе `Authentication failed` при `git clone` | токен GitHub скопирован с ошибкой или нет доступа Contents: Read — используйте запасной вариант шага 5 |
| шаг 6: `permission denied … docker.sock` | вы подключились, пока сервер настраивался: отключитесь в Termius и подключитесь снова |
| в логе `Killed` или сборка оборвалась | пришлите последние 30 строк лога (`tail -n 30 /var/log/kovsh-stand.log`) |
| админка: «соединение не защищено» дольше 10 минут | проверьте, что порты 80 и 443 открыты; пришлите `docker compose logs web | tail -30` |
