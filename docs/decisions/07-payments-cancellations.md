# Решения Ф-2, Ф-3, Н-25…Н-27, схема оплаты физлиц и юрлиц, отмены (дополнение к ТЗ)

> Статус: **утверждено заказчиком** (22.11.2026). Приоритет: **07 > 06 > 05 > 04 > 03 > 02 > 01 > план > ТЗ v1.0**.

| № | Решение |
|---|---|
| Ф-2 | Без независимого диспетчера платформа получает всю комиссию — 12% от полной суммы заказа (аренда + доставка). |
| Ф-3 | Удержанная по решению поддержки сумма делится от **фактически удержанной суммы**: без диспетчера 88% исполнителю / 12% платформе; с диспетчером 88% / 7% диспетчеру / 5% платформе. |
| Н-25 | Однодневный заказ компания может принять только при наличии свободного проверенного машиниста с учётом календаря занятости. |
| Н-26 | Многодневный заказ — один или несколько машинистов. Можно назначить одного машиниста сразу на все смены или разных — на разные дни. Машинист закрепляется только за теми сменами, на которые назначен. Техника закреплена весь период. Замена — по прежним правилам. |
| Н-27 | Заказ независимого диспетчера: SMS со ссылкой фактическому заказчику → заказчик подтверждает → только после этого запускается поиск. Схема оплаты — по типу фактического заказчика. Платит и получает документы фактический заказчик, регистрация не обязательна. |
| Оплата физлиц | После принятия исполнителем — **100%** стоимости, 10 минут на оплату, иначе автоотмена без повторного поиска. |
| Оплата юрлиц | После принятия — 50% (онлайн, 10 минут), остальные 50% — в течение 24 часов после окончательного завершения. Оплата по счёту для предварительных заказов (К-1) сохраняется. Неоплата второй части — долг и блокировка новых заказов (Н-9, К-9). |
| Отмены | Каждая отмена после оплаты рассматривается поддержкой индивидуально: полный возврат, частичный возврат или полное удержание, с причиной; решение и действия сотрудника — в истории заказа и журнале. Автоматического возврата и автоматического удержания нет. Распределение удержанного — по Ф-3. |

## Что меняется в ранее согласованном

| Было | Стало |
|---|---|
| В 4.1–4.2: всем 50% после принятия и 50% после выполнения | Физлица — 100% после принятия; юрлица — 50/50 |
| Н-13: после предоплаты 50% не возвращаются автоматически | Решение принимает поддержка: полный, частичный возврат или полное удержание |
| Н-12, К-10: удержанные 50% делятся по комиссии | То же правило, но от фактически удержанной суммы (Ф-3) |
| Н-9, К-9: долг по второй части | Только для юрлиц (у физлиц второй части нет) |

## Противоречия и вопросы

**Н-28. Дополнительное время у физлица.** По Н-5 доплата за дополнительные часы входит «во вторую часть платежа», но у физлиц второй части больше нет (100% вперёд). Как физлицо оплачивает продление? *Предложение: после того как заказчик подтвердит запрос машиниста, сразу выставляется онлайн-оплата дополнительных часов; машинист продолжает работу после оплаты (или сразу — тогда неоплата становится долгом).*

**Н-29. Возврат, когда заказчик не виноват.** К-8 (п. 9) и Н-14 утверждали **автоматический** 100% возврат, если исполнителя не нашли или замену не удалось найти. Новое правило: «автоматически возвращать деньги при любой отмене нельзя, если заказчик не виноват — тоже индивидуально». *Сейчас реализую по новому правилу: такие случаи тоже уходят на решение поддержки. Подтвердите или верните автоматический полный возврат для случаев «исполнитель не найден / замена не найдена».*

**Н-30. Как определяется тип заказчика.** *Предложение:* в профиле заказчик может добавить одно или несколько юрлиц (ИНН с проверкой контрольного числа, название, КПП, юридический адрес, email для документов). При оформлении выбирает, кто платит: «я (физлицо)» или одно из своих юрлиц. Для заказа диспетчера тип выбирает фактический заказчик по SMS-ссылке.
