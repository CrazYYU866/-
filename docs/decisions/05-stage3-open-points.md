# Этап 3: решения разработки, которые нужно подтвердить

> В ТЗ и решениях 01–04 этих правил нет. Я реализовал разумный вариант, чтобы не останавливать работу.
> Каждый пункт легко поменять. Отметьте «ок» или напишите своё.

| № | Как сделано сейчас | Где в коде |
|---|---|---|
| **С-1** | Реквизиты организации (название, ИНН, адрес и т. п.) можно править только в статусах «Черновик» и «Отклонён». После подтверждения — только через поддержку. | `OrganizationsService.update` |
| **С-2** | Разблокированная организация возвращается в «Подтверждён», если была подтверждена до блокировки, иначе в «Черновик». | `ModerationService.unblockOrganization` |
| **С-3** | При передаче главного владения (Р-12) прежний владелец остаётся в компании руководителем. Отвязать его может новый владелец. | `ModerationService.transferOwnership` |
| **С-4** | Права ролей админки: подтверждение/отклонение организаций и документов — суперадмин и модератор; блокировка организаций и пользователей, передача владения — суперадмин и поддержка; просмотр файлов документов — суперадмин, модератор, поддержка (финансист не видит паспорта); просмотр настроек — суперадмин и финансист; изменение настроек — только суперадмин. | `admin.controllers.ts` |
| **С-5** | Документы машиниста загружают руководители компании и сам машинист. | `PartnerMembersController` |
| **С-6** | Диспетчер видит список сотрудников своей компании (нужно для назначения машинистов). Документы и реквизиты компании видят только руководители. | `PartnerMembersController`, `OrganizationsService.view` |
| **С-7** | Стартовый список документов (В-32): для ИП/ЮЛ — лист записи ЕГРЮЛ/ЕГРИП, документ о постановке на учёт (ИНН), для юрлиц — документ о полномочиях руководителя; для техники — ПСМ/ЭПСМ, СТС, право собственности или пользования; для машиниста — паспорт, удостоверение тракториста-машиниста (необязательное, требование по категориям техники — этап 4). Список редактируется в БД, раздел в админке появится вместе с веб-панелью. | миграция `0003` |
| **С-8** | Организация подтверждается только после того, как модератор одобрил все обязательные документы. | `ModerationService.approveOrganization` |
| **С-9** | Технические параметры безопасности админки: блокировка входа на 15 минут после 5 неверных паролей, сессия администратора 12 часов, 2FA (приложение-аутентификатор) включается самим администратором. Сделать 2FA обязательной для всех администраторов? | `AdminAuthService` |

## Этап 4: решения разработки, которые нужно подтвердить

| № | Как сделано сейчас |
|---|---|
| **С-10** | Если у проверенной техники меняются категория, марка, модель, год или госномер — она снимается с линии и уходит на повторную проверку. Радиус, база, характеристики, фото, расписание меняются без повторной проверки. |
| **С-11** | Каталог, характеристики, единицы измерения, регионы и тарифы меняет только суперадминистратор. Смотреть могут все администраторы. Нужно ли дать право менять тарифы финансисту? |
| **С-12** | Какие характеристики обязательны (вы не указали): по одной ключевой на группу — эксплуатационная масса (экскаваторы, дорожная техника), грузоподъёмность (погрузчики, самосвалы, автокраны, трал), грузоподъёмность автомобиля и манипулятора (манипуляторы), рабочая высота (автовышки), мощность (МТЗ). Остальные — необязательные. Меняется в админке. |
| **С-13** | «Наличие гидромолота и другого навесного оборудования» сделано двумя полями: «Гидромолот» (да/нет) и «Другое навесное оборудование» (текст). «Тип кузова», «Тип катка», «Тип навесного оборудования» — текстовые поля, а не списки: варианты вы не перечислили. Администратор может заменить их на списки. |
| **С-14** | Год выпуска обязателен для всех видов, кроме трала (у трала в вашем перечне года нет). Флаг «год обязателен» настраивается для каждой категории. |
| **С-15** | Тариф можно задать у группы, подгруппы или конкретного вида. Действует самый «близкий»: сначала тариф вида, затем подгруппы, затем группы. |
| **С-16** | Москва и Московская область заведены отдельными регионами с одинаковыми стартовыми ценами. |
| **С-17** | Для документов техники обязательным сделано только «Подтверждение права собственности или законного пользования». ПСМ/ЭПСМ и СТС — необязательные, так как не у всей техники есть оба (В-32: «в зависимости от вида техники»). |
