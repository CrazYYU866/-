# Полный список: что подключить и настроить для запуска и проверки «Ковш на Час»

Состояние на 24.11.2026. Обозначения: **Вы** — действия заказчика, **Я** — разработка, **Юрист/бухгалтер** — решения до подключения.

> **Важно о готовности интеграций.** Для каждого внешнего сервиса в коде есть готовый интерфейс и тестовая
> реализация; всё остальное (бизнес-логика, база, приложения) от выбора провайдера не зависит. **Сами классы
> подключения к реальным сервисам (Яндекс, SMS, push, телефония, ЮKassa) ещё не написаны** — они пишутся,
> когда у вас появляются ключи и выбран провайдер, и проверяются на тестовом стенде. Объём каждого — от нескольких
> часов до 1–2 дней (оценки ниже). Почему так: проверить подключение без ключа нельзя, а писать вслепую — значит
> сдавать непроверенный код.

## 2. Нужно сейчас (этапы 1–2)

### 2.1. Yandex Cloud — тестовый стенд (с ноутбука)

Пошаговая инструкция — **`docs/FIRST_STEPS.md`** (шаги 1–2: ключ SSH, постоянный IP, сервер, 5 команд).
Можно проще — сервер настроит себя сам: при создании ВМ вставьте текст из **`infra/stand/user-data.yaml`**
в метаданные `user-data` (как в `docs/IPHONE_SETUP.md`, шаг 4) — команды набирать не придётся.

* Сервер: Ubuntu 24.04, 2 vCPU, 4 ГБ RAM, SSD 40 ГБ, постоянный публичный IP, порты 22/80/443.
* Стоимость: такой сервер — порядка нескольких тысяч рублей в месяц; у новых аккаунтов бывает стартовый грант
  (условия — в консоли Yandex Cloud). Сервер можно останавливать, когда не нужен (платится только диск).
* Итог: адрес API вида `https://api.<IP>.sslip.io` — **присылаете мне**.

### 2.2. Expo — сборки приложений и Expo Go

* **Вы:** регистрация на expo.dev → Account settings → Access tokens → Create token (`docs/FIRST_STEPS.md`, шаг 3).
  Токен — только через защищённую форму, не в чат. Бесплатно; бесплатного лимита облачных сборок хватает для тестирования.
* **Я:** открываю этой среде доступ к серверам Expo (вас попросят подтвердить), публикую оба приложения для Expo Go,
  собираю APK для Android и сборки для разработки.

### 2.3. Google Play Console — по желанию на этапе 2

* Для установки APK на Android **не нужен** — APK ставится по ссылке.
* Нужен для внутреннего тестирования через Play и для публикации: регистрация разработчика (разовый взнос,
  сумму смотрите на play.google.com/console), подтверждение личности; для компании — данные организации.

### 2.4. Apple Developer Program — для iPhone-сборок

* Без него: только Expo Go (без фонового GPS и push).
* С ним: сборки для своих iPhone (регистрация устройств по ссылке), TestFlight, App Store.
* **Вы:** developer.apple.com → Enroll. Физлицо — быстрее (1–2 дня); компания — нужен номер D-U-N-S (бесплатный,
  1–2 недели). Годовой взнос — по тарифу Apple.
* Передавать мне Apple ID не нужно: при первой сборке вы один раз входите в Apple через Expo (или выдаёте ключ App Store Connect API через защищённую форму).

### 2.5. GPS-отслеживание машиниста — ничего подключать не нужно

Уже сделано: фоновая передача с «Выехал» до «Прибыл», офлайн-очередь, пояснение перед запросом разрешения,
хранение 48 часов, доступ только участникам заказа. **Нужны только сборки (п. 2.2) и телефоны** — в Expo Go фон не работает.
Карта для отслеживания — см. п. 3.1 (MapKit); до неё показывается схема «техника → объект» с расстоянием.

## 3. Внешние сервисы (этап 3)

### 3.1. Яндекс: адреса, расстояния и карты

Ключи берутся в **Кабинете разработчика Яндекса** (developer.tech.yandex.ru) — для каждого продукта свой ключ.
Для коммерческого сервиса нужна **коммерческая лицензия** (бесплатные условия Яндекса не разрешают использование в
платных сервисах — проверьте актуальные условия и тарифы в кабинете).

| Продукт | Для чего у нас | Что передать мне | Что делаю я | Оценка |
|---|---|---|---|---|
| **API Геосаджеста** | подсказки адреса объекта при вводе | ключ (защищённая форма) | класс `GeocoderProvider` (подсказки) | 0,5 дня |
| **HTTP Геокодер** | адрес ↔ координаты, «Я на объекте» | ключ | обратное геокодирование в том же классе | вместе с геосаджестом |
| **API маршрутизации / матрица расстояний** (Яндекс Карты, с учётом пробок) | км доставки по дорогам, время в пути, подбор исполнителя, время прибытия | ключ | класс `RoutingProvider`; перемер нагрузочного теста (на каждый заказ — несколько запросов) | 1 день |
| **MapKit SDK** (мобильный) | карта в приложениях: объект, техника, движение машиниста | ключ | замена схемы `RouteScheme` на карту; работает только в сборках (не в Expo Go) | 1–2 дня |

Примечание о названиях: «Яндекс Маршрутизация» как отдельный продукт — сервис планирования маршрутов курьеров;
нам нужен **расчёт маршрута/расстояния** из API Яндекс Карт. Если сомневаетесь, какой продукт заказывать в кабинете — пришлите скриншот списка, подскажу.

**Также нужны данные, а не ключи** (настраиваются в админке): тарифы доставки за км по видам техники;
точные границы Москвы и МО (GeoJSON) — сейчас прямоугольники «ДЕМО».

### 3.2. SMS — коды входа и ссылки на заявки

* **Вы:** выбрать провайдера (например SMS.ru, SMSC, МТС Exolve, Devino — любой с HTTP API), договор, пополнить баланс;
  зарегистрировать **буквенное имя отправителя** «KovshNaChas» (регистрируется у операторов, обычно 1–3 недели и платно;
  до регистрации — общее имя провайдера).
* **Передать:** ключ API (форма), имя отправителя.
* **Я:** класс `SmsProvider`, лимиты уже есть. **0,5 дня.**

### 3.3. Push-уведомления

* **Рекомендую Expo Push** (бесплатно, работает поверх FCM/APNs; приложения уже регистрируют токены).
* **Вы:** проект Firebase (console.firebase.google.com) → приложение Android `ru.kovshnachas.client` и `ru.kovshnachas.partner` →
  ключ сервисного аккаунта; для iPhone — ключ APNs в Apple Developer (после п. 2.4). Оба загружаются в Expo
  (`eas credentials`) — могу сделать сам, если передадите файлы через защищённую форму.
* Устройства без сервисов Google (Huawei и др.) — **RuStore Push**, отдельно, по желанию позже.
* **Я:** класс `PushProvider` для Expo Push, обработка недействительных токенов. **0,5–1 день.**

### 3.4. Подменные номера (звонки без раскрытия телефонов)

* **Вы:** выбрать провайдера с услугой «номер-маска» / переадресации с записью (например МТС Exolve, Mango Office,
  Voximplant), договор, номера.
* **Передать:** ключ API, номера.
* **Я:** класс `TelephonyProvider` + приём записей разговоров. **1–2 дня.**
* **Юрист:** уведомление о записи разговоров (п. 5).

### 3.5. Оплата — ЮKassa

* Тестовый магазин ЮKassa даётся после регистрации — **песочницу можно подключить до юридических решений**.
* **Вы:** регистрация на yookassa.ru (ИП или ООО), тестовый магазин → shopId и секретный ключ.
* **Я:** класс `PaymentProvider`: оплата, возвраты, уведомления (уже готова асинхронная обработка). **1–2 дня** для песочницы.
* **До боевого подключения:** решения юриста и бухгалтера (п. 5): агентская схема, **чеки 54-ФЗ** (ЮKassa или своя
  онлайн-касса), НДС, **выплаты исполнителям** (отдельный продукт ЮKassa «Выплаты» или банк).

### 3.6. Хранение файлов — Yandex Object Storage

* **Вы:** в Yandex Cloud: Object Storage → бакет (приватный) → сервисный аккаунт с ролью `storage.editor` → статический ключ.
* **Передать:** ключ (форма), имя бакета.
* **Я:** включаю (драйвер уже написан и проверен на эмуляторе). **1 час.**

### 3.7. Электронная почта — счета юрлицам и уведомления

Сейчас счёт создаётся в системе, но **PDF-файл и отправка письма не реализованы** (в приложении это так и написано: «Счёт выставлен»).
* **Вы:** почтовый домен (например Yandex 360 для бизнеса) или Yandex Cloud Postbox; адрес отправителя.
* **Я:** формирование PDF счёта (могу начать без ключей) и отправка письмом. **1–2 дня.**

### 3.8. DaData — по желанию

Автопроверка ИНН/ОГРН при регистрации компаний; бесплатный лимит обычно достаточен. **Вы:** ключ API. **Я:** **0,5 дня.**
